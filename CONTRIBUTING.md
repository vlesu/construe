# How to contribute to construe

Thank you for wanting to help the project. The main way to help is to report a bug: the program is developed by its
author, and every report is read. Below: how to report a bug and how to suggest a change.

## Reporting a bug

- **From the program** — “Help” → “Report a problem…” ([guide](docs/user/guide.en.md#9b-reporting-a-problem), §9b).
  The program log, the version and the system are attached to the report automatically, after a crash — a dump as well;
  window screenshots and the part file are attached at your choice (clear the “Attach the part file to reproduce the problem”
  check box if the part must not be shared). The e-mail address is needed only for the reply and is never
  published. If the server cannot be reached, the program offers to save the report as a zip file.
- **Through GitHub issues** in this repository: what you did, what you expected, what happened, the program version
  (Help → About) and the system; if possible — the steps to reproduce, a screenshot or a small part file.
- **Do not post personal data** in issues: addresses, paths containing a user name, parts and drawings that must not be
  shared openly. It is better to send such things from the program — the report is seen only by the developers.
- The answer comes as a comment in the issue or as a letter to the address given in the report; the fix is released in
  one of the following versions.

## Suggestions and pull requests

- **Pull requests to the code are not accepted (not merged).** The program is developed by the project authors.
- A suggestion can be sent as a pull request or described as an idea in an issue: what to change and why, if possible —
  how to check it. The project authors will review it and, if the suggestion fits, make similar changes themselves; the
  pull request itself is closed afterwards.
- A contributor license agreement (CLA) is not required and is not signed.
- In suggestions, do not use code, fonts, icons or data of others without a license compatible with the project license
  (the third-party elements and their licenses — [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES)); standards data — only
  the numeric values of tables with the standard cited, without the texts and drawings of the editions.
- Do not mention the names of other programs: describe the behavior («rotation with the middle button», not «as in …»).
- Building the program from source — [docs/user/build.en.md](docs/user/build.en.md).
