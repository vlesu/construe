## 0.1.0-alpha — the first public release

The first version of construe open to everyone. What the program can do is described in the
[user guide](guide.en.md), installation — [here](install.en.md).

- Sketches with constraints and dimensions, a live solver, expressions and variables in any field.
- Parts: extrude, revolve, sweep, loft, holes, threads, shell, fillets, chamfers, patterns; a feature tree with
  rollback and editing; sheet metal parts with a flat pattern exported to DXF.
- Assemblies with mates, exploded views, interference check.
- Drawings and bills of materials to GOST and ISO; printing and export to PDF, SVG, DXF.
- A library of standard parts and a wizard for standard connections.
- STEP, STL and 3MF import and export, exchange with FreeCAD (`.FCStd`), design recognition of an imported body.
- The interface and the user guide in English and Russian.
- Updating the program at the press of a button and reporting a problem right from the program.

**Limitations of the alpha:** expect bugs — please report them. Windows 10/11 64-bit, Linux x86_64, macOS 13.3+ on a Mac with an Apple processor. The installers are not signed with
a paid certificate — how to get past the system warning is described in the [installation guide](install.en.md).
