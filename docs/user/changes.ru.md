# construe — что нового

*English version: [changes.en.md](changes.en.md). Обе версии ведутся синхронно.*

## 0.1.0-alpha — первый публичный выпуск

Первая версия construe, открытая для всех. Что умеет программа — в [руководстве пользователя](guide.ru.md),
установка — [здесь](install.ru.md).

- Эскизы с ограничениями и размерами, решатель «на лету», выражения и переменные в любом поле.
- Детали: выдавливание, вращение, протягивание, лофт, отверстия, резьба, оболочка, скругления, фаски, массивы;
  дерево построения с откатом и правкой; листовые детали с развёрткой в DXF.
- Сборки с сопряжениями, разнесённый вид, проверка пересечений.
- Чертежи и спецификации по ГОСТ и ISO; печать и экспорт в PDF, SVG, DXF.
- Библиотека стандартных деталей и мастер стандартных соединений.
- Импорт и экспорт STEP, STL, 3MF, обмен с FreeCAD (`.FCStd`), распознавание конструкции импортированного тела.
- Интерфейс и руководство на русском и английском.
- Обновление программы по кнопке и сообщение о проблеме прямо из программы.

**Ограничения альфа-версии:** возможны ошибки — пожалуйста, сообщайте о них. Windows 10/11 64-бит, Linux x86_64, macOS 13.3+ на Mac с процессором Apple. Установщики не подписаны платным
сертификатом — как пройти предупреждение системы, написано в [инструкции по установке](install.ru.md).
